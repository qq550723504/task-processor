# ListingKit 管理员店铺统计页展示店铺 ID

## 目标

在 `/listing-kits/admin/store-statistics` 的统计表格中明确展示每个店铺的数字主键 `id`，同时保留现有业务店铺标识 `storeId`。

## 当前上下文

- 统计接口已经返回 `id` 和可选的 `storeId`。
- 当前“店铺”单元格展示店铺名称，并优先展示 `storeId`；只有 `storeId` 为空时才显示 `#id`。
- 管理员视图额外展示租户信息，租户视图不展示租户 ID。

## 方案

在表格中新增独立的“店铺 ID”列，直接展示 `item.id`，放在“店铺”列之后；“店铺”列继续展示名称和业务 `storeId`。加载和空数据行的 `colSpan` 从 6 调整为 7。

这样数据库主键和业务店铺标识的含义分离，便于管理员按数字 ID 排查，同时不影响现有业务标识的识别。

## 数据流与边界

无需修改后端接口、API schema 或路由。页面直接使用已通过 `ListingStoreStatistics` 类型校验的 `id` 字段。管理员视图和租户视图共用同一表格，因此两者都会展示店铺 ID。

## 测试与验收

- 组件测试验证统计行显示数字店铺 ID。
- 组件测试继续验证店铺名称、统计数据和租户视图行为。
- 运行统计页组件测试及相关 UI 类型检查，确认新增列不会破坏现有表格结构。

验收标准：管理员统计页每一行都有清晰的“店铺 ID”列，显示数字主键；现有 `storeId` 仍然可见；无数据和加载状态布局正常。
