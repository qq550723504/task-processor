# ListingKit 租户店铺页展示店铺 ID

## 目标

在 `/listing-kits/stores` 的租户店铺主数据表格中新增独立的“店铺 ID”列，明确展示数字主键 `id`，同时保留店铺名称和现有业务店铺标识。

## 当前上下文

- 租户店铺接口已经返回 `ListingStore.id` 和可选的 `storeId`。
- 当前“店铺”单元格已经显示店铺名称，并在下方以 `#store.id` 显示数字 ID，但没有独立列。
- 页面表格当前有 7 列，加载和空数据状态使用 `colSpan={7}`。

## 方案

在“店铺”列后新增“店铺 ID”列，直接展示 `store.id`；移除“店铺”列中重复的 `#store.id`，改为在名称下展示业务 `storeId`（如接口提供）。加载和空数据行的 `colSpan` 从 7 调整为 8。这样与管理员统计页的 ID 展示方式一致，便于按数字主键定位店铺。

## 数据流与边界

无需修改后端接口、API schema、路由或表单。页面直接复用已校验的 `ListingStore.id` 字段。新增列只影响 `/listing-kits/stores` 的列表展示，不改变新增、编辑、删除、登录和筛选行为。

## 测试与验收

- 租户店铺目录组件测试验证表头“店铺 ID”和数字 ID 单元格可见。
- 现有店铺名称、登录状态、操作链接、表单和移动端布局测试继续通过。

验收标准：租户店铺页每行都有清晰的“店铺 ID”列，显示数字主键；现有店铺标识和全部操作行为不受影响；加载和空数据状态覆盖完整表格宽度。
